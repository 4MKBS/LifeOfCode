Sticky Header & Footer Demo

What is a Sticky Header?

A sticky header stays fixed at the top of the viewport as you scroll down the page. It uses position: sticky; top: 0; to remain visible, providing easy access to navigation at all times.

What is a Sticky Footer?

A sticky footer stays fixed at the bottom of the viewport as you scroll. It uses position: sticky; bottom: 0; so that important information or links are always accessible.

How It Works

The layout uses a flexbox column on the body with min-height: 100vh. The main content area has flex: 1 so it expands to fill available space. Both the header and footer use position: sticky to stay pinned to their respective edges.
